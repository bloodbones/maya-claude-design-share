Codex handoff — implementation spec
Full SwiftUI contracts, accessibility notes, and edge cases for both features

Search

Tap the magnifying glass in the top-right to open a search overlay. Results span all conversations. Tap any result to jump to that thread with the matching bubble highlighted and an in-thread nav strip.

Trigger & entry

  • Icon placement: 36×36 tap target, top-right of top bar, vertically centered with model picker. Color --ink-2 at rest.
  • Open animation: 200ms spring (damping 0.78, response 0.35). Overlay slides from y=−120 to y=0; thread fades to opacity: 0.35 simultaneously.
  • SwiftUI: .sheet(isPresented:) { SearchOverlayView() } with presentationDetents([.fraction(0.55), .large]) — starts at 55%, expands on keyboard.
  • Dismiss: Cancel button, swipe down, or tap the dimmed thread.

Search bar

  • Border 1.5px solid var(--accent), outer glow 0 0 0 4px var(--accent-tint). Auto-focuses on open.
  • Placeholder: Search conversations… — Plus Jakarta Sans 16 / --ink-3 (not Fraunces italic).
  • SwiftUI: searchable(text: $query) on the overlay view, not the parent.

Recent searches

  • Show when field is empty. Max 5 recents. Stored in UserDefaults key maya.searchRecents.
  • Row height 44pt min. Swipe left → red "Delete". Section header "Clear" clears all.

Results

  • Index: Full-text across all thread messages. Use SQLite FTS5 index (recommended for offline perf) or CoreSpotlight.
  • Layout: Flat chronological list, most recent first. Thread name (600/13px) + snippet italic serif 15px + timestamp mono 10px. Min 56pt row height.
  • Highlight: NSAttributedString with background --accent-tint, foreground --accent-deep, corner radius 3pt on matching term.
  • Snippet: 2-line clamp; match centered. Use NSString.range(of:options:.caseInsensitive), extract ±80 chars around offset.
  • Empty: Fraunces italic 18 / --ink-3 — Nothing matched "…".
  • Perf: Debounce 200ms. Show skeleton rows on first keystroke.

Jump to match

  • Tap result → dismiss overlay (reverse spring, 180ms) → navigate to thread → scroll to message ID.
  • In-thread nav strip (36pt tall): "1 of N matches · query", ↑↓ arrows, ×. Background rgba(247,242,235,0.92) + UIBlurEffect.systemUltraThinMaterial.
  • Matched bubble: 600ms accent-tint background pulse via withAnimation(.easeOut(duration: 0.6)).
  • Scroll: ScrollViewReader { proxy in proxy.scrollTo(messageId, anchor: .center) }.

Message queue

While Maya is streaming, the composer stays fully live. Sending adds the message to a local queue — it appears immediately as a ghost bubble and sends automatically, in order, once Maya finishes.

Streaming state

  • Indicator: Thinking… row — 14px circular spinner (terracotta on --accent-soft track) + label. Disappears when first token arrives.
  • Streaming bubble: Text streams in as tokens arrive. Blinking 2×18pt cursor at insertion point. Animation.linear(duration: 0.5).repeatForever() on opacity 0→1→0.
  • Stop button: Send morphs to terracotta circle + white square. Transition: withAnimation(.easeInOut(duration: 0.14)) on isStreaming.
  • Composer: Fully active. User types and sends normally during streaming.

Queue model

  • MessageQueue: [QueuedMessage] in the conversation ViewModel. Each item: id: UUID, text: String, createdAt: Date.
  • Send during streaming → append to queue, clear composer, show ghost bubble immediately.
  • Streaming ends → dequeue one, send it, await response, dequeue next. One in-flight at a time.
  • Queue lives in @State only. Not persisted to disk. Lost on background.

Queue strip

  • Appears above composer when ≥1 queued. Disappears when empty.
  • Content: count + sends after Maya finishes + "Clear" (danger).
  • Tap to expand queue manager sheet.
  • SwiftUI: VStack(spacing: 0) { QueueStripView(); ComposerView() }. Strip 44pt. Transition: .move(edge: .bottom).combined(with: .opacity).

Ghost bubbles

  • Same --accent-tint as user bubbles, opacity: 0.55. No shadow, no timestamp.
  • Below bubble: 12px clock SVG + queued mono label (10px / 0.12em / --ink-3), right-aligned.
  • On send: opacity → 1.0 over 300ms, clock fades out, timestamp fades in. withAnimation(.easeOut(duration: 0.3)).

Queue manager (Q3 expanded)

  • Bottom sheet detent: .fraction(0.35). Tap strip to open.
  • Row: drag grip + preview (1-line truncated) + pencil edit + ✕ cancel.
  • Reorder: Long-press grip → drag. List { ForEach }.onMove or custom gesture. Ghost bubbles reorder live in thread.
  • Edit: Tap pencil → inline field replaces preview. Confirm on blur/return.
  • Cancel single: Tap ✕ → remove from queue + ghost bubble. Transition: .opacity.combined(with: .scale(scale: 0.95)).
  • Clear all: Danger button. Haptic: UINotificationFeedbackGenerator().notificationOccurred(.warning).

Edge cases

  • Stop during stream: Partial bubble stays, marked Stopped. in --ink-3. Queue is preserved — not discarded.
  • Send error: Ghost bubble gets danger border + [Retry] chip. Queue pauses until retry or dismiss.
  • 5+ queued: Ghost bubbles past 3 collapse to a +N more queued → chip. Tap to expand manager.

Accessibility

  • Search icon: accessibilityLabel("Search conversations"). On open: UIAccessibility.post(notification: .screenChanged, argument: searchField).
  • Ghost bubble: accessibilityLabel("Queued: [text]"). Not re-announced on send — timestamp appearance is the confirmation.
  • Queue strip: accessibilityLabel("[N] messages queued, sends after Maya finishes").
  • Stop: accessibilityLabel("Stop response"). Both Stop and Send use accessibilityAddTraits(.isButton).
  • Reduce Motion: Ghost bubble opacity snaps (no animate). Search overlay uses simple fade, no spring.
